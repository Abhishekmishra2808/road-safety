================================================================================
📊 WHAT THE SYSTEM DOES
================================================================================

1️⃣ EXTRACT FRAMES
   → Extracts frames from base and present videos at 1 FPS
   → Creates metadata JSON with timestamps
   → Output: JPG images + metadata

2️⃣ ALIGN FRAMES
   → Matches frame pairs between base and present
   → Uses ORB/SIFT feature detection
   → Computes homography with RANSAC
   → Warps present frames to align with base
   → Output: Aligned image pairs

3️⃣ DETECT ELEMENTS
   → Runs YOLOv8 on all frames
   → Detects: signs, poles, vehicles, etc.
   → Also detects road markings and potholes
   → Output: Bounding boxes + confidence scores

4️⃣ MATCH & COMPARE
   → Matches detections using IoU
   → Computes SSIM for image similarity
   → Calculates severity scores
   → Output: Matched pairs + change metrics

5️⃣ GENERATE REPORTS
   → Creates side-by-side evidence images
   → Annotates with bounding boxes (color-coded by severity)
   → Generates CSV with all changes
   → Creates PDF executive summary
   → Output: images/ + changes.csv + summary.pdf

🎨 COLOR CODING IN EVIDENCE IMAGES

🟣 Magenta:  Missing elements (present in base, not in present)
🔵 Cyan:     New elements (not in base, present in present)
